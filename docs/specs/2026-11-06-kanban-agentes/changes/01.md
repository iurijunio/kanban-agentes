# Mudanças após a aprovação — passo 07

- **`runtime="nodejs"` removido das rotas de API**: incompatível com `cacheComponents`
  no Next.js 16.4.5 (o build quebrava). Os handlers continuam em Node por padrão;
  `npm run build` passa.
- **Drop na mesma coluna é no-op na UI**: `board.tsx` ignora o drop quando o card já
  está na coluna de destino. A API `POST /api/cards/:id/mover` continua aceitando
  mover para a mesma coluna (registra histórico), conforme a spec.
- **`*.tsbuildinfo` no `.gitignore`**: o `tsconfig.tsbuildinfo` deixou de aparecer
  como untracked.
- **`.env.local` de teste local não versionado**: já coberto por `.env*.local`;
  permanece apenas na máquina de quem roda o projeto.
