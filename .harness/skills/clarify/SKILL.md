---
name: clarify
description: Ask before assuming. Use when a request has more than one reasonable reading, or lacks scope, data or an acceptance criterion.
---
## Steps
1. List what is unclear; drop what the code or memory answers.
2. Ask one question at a time, with options and your recommendation first.
3. Stop when you can state the goal, the scope and how to verify it in 3 lines. Show them before starting.
Tiny and reversible: state the assumption and proceed.
